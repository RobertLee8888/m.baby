## Corrected Findings

| Finding | Correction |
| --- | --- |
| Reset during refresh allowed old asynchronous work to insert cards again | Every refresh phase checks an epoch; reset invalidates prior work and clears motion/loader state |
| Reload on Following showed Feed despite the active history entry | Restore the Following destination and its Feed/Me origin |
| Market Following was a static, separate list | Use the same followed set as Feed and Me; changes propagate immediately |
| Selected filter used a text token as a surface | Bind to `content/br10`, with inverse text |
| Arrow inherited chip elevation and overly dark ink | Border only; `text/n5` for the exact arrow asset |
| Search lacked its surface role and used the wrong placeholder tone | `module/b-data-entry`, `text/n3`, `Button/radius-btn-m` |
| Dialog used a content surface token | `module/b-dialog` |
| Count direction reused brand accents | Dedicated `price/up` and `price/down`, including their dark values |
| Following reused incorrectly framed stock logos | Use Figma Logo/Stock exports; preserve vector and bitmap formats separately from the feed-card variant |
| Newly followed BTC has a component logo, not an image URL | Reuse the existing Market BTC component; no undefined image request |
| Feed body budget had no density ceiling | Maximum 573px, or the available short-screen height; keep the specified first-sentence floor |
| A long first word could be clipped or leave only an ellipsis | Wrap long tokens; use grapheme boundaries when word boundaries cannot fit |
| Quote expansion measured transformed rather than logical pixels | Animate logical layout height so sub-360px scaling remains correct |
| Source dialog allowed background focus | Background is inert, focus is contained, Escape/close restores the trigger |
| Source avatar inset shadow could paint behind the image | Draw the hairline above the bitmap with an inset outline |

Spacing and content/button radii for the changed components now use named
Alva-Library aliases. Source and quote variants still share one renderer and one
source record; no screen-sized images or additional runtime dependency were added.

For COIN/HOOD, the approved Following examples supply identities but no market
snapshot. The demo retains their identities and follow actions, leaves the price
unavailable, and does not generate additional prices or charts for them.

## Verification

- Five pure data tests: symbol aliases, 48-hour boundary, deduplicated counts,
  latest-mention order and refresh of an older ticker.
- Browser regression: all 14 P01-P07 / S01-S07 variants, nested references,
  external-link attributes, expand, filter, search/clear, history and refresh.
- Mobile widths: 320, 360, 393 and 430px. Short-screen folding checked at 640px
  high; standard reference viewport 393x852. Width 320 uses a logical 360px layout.
- Light and Dark: selected surface, placeholder/icon tones, module surfaces and
  radii checked against resolved tokens. Mutating tokens confirms actual bindings.
- Restart checked at 100, 800, 1950 and 2650ms into refresh, then another successful
  refresh. No stale cards, disabled filters or leftover pull animation.
- Following reload from both Feed and Me, follow/unfollow propagation, selection
  fallback to All, long-word/CJK expansion and source dialog keyboard behavior.
- Newly followed BTC appears in Following with its component logo; selecting it
  reaches the empty filtered feed and Clear filters returns to All.
- Chromium mobile emulation, DPR 1 and 2; no page errors or missing image assets.
  This is not a physical iPhone/Safari certification.

## Remaining Visual Differences

Do not call this pixel-identical. The P01 gray quotation at 361px is 134px high
in Chromium versus 156px in Figma (node `4242:46792`). Its paragraph wraps to
three lines instead of four. The raw text, font family/weight/size, 22px line
height and 337px text width match; Figma specifies 1% tracking while the web
paragraph currently uses zero tracking. There is no hidden text or clipped line.
The complete 14-variant height comparison found these five differences:

| Variant | Surface | Figma height | Chromium height | Difference |
| --- | --- | --- | --- | --- |
| P01 | Gray quote | 156px | 134px | -22px |
| P04 | Gray quote | 230px | 208px | -22px |
| P07 | Gray quote | 277px | 255px | -22px |
| S01 | Gray quote | 166px | 144px | -22px |
| P07 | Source row | 391.0625px | 369.0625px | -22px |

The other 23 surface heights match. Equal height alone does not certify every
pixel or every word boundary. Functional assertions pass; the five text-wrap
differences remain an explicit visual acceptance exception, not a passed gate.

The gray fill remains the actual `content/br03` token. A standalone Figma export
composited on the gray canvas is not a replacement hex color for the quotation
rendered on the white Feed surface.

Following rows intentionally omit counts/times and sort by the loaded demo's
latest mentions, per the final note, rather than copying the older example
screenshot's static row order and counts. Native mobile system bars remain omitted.
