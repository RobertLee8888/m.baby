## Implementation

The gallery entry is renamed Thesis. The existing `#/mvp-social` and shared-post URLs remain compatible.
The original MVP entry keeps its separate layout and behavior.

V5 cards share one renderer across For You, Me, bookmarks, related theses and details.
The homepage has nine supplied examples in the requested order. New/update tags,
publisher role, dates, bookmark counts and the Single/Multiple/None variants come
from the current instances. Each card has one continuous bottom divider.
Charts retain the actual instance image fills at 240 x 135; horizontal galleries
reach and clip at the screen edges. Monochrome SVG paths use theme tokens without
multiplying the exported opacity. The create icon is the actual Library instance.

Auto previews preserve the supplied summary. The manual Gavin preview measures
the complete card against the stable page viewport, including its reserved controls.
It truncates only the narrative at a word boundary when required. Layout measurement
uses untransformed dimensions so splash and navigation cannot alter the result.
Details retain the full article and native dotted-underlined source domains, with
the supplied trailing Unicode arrow in Noto Sans Symbols 2. Sources still opens the
existing source records. No inline list expansion is reintroduced.

Search supports recent visits, individual removal, clear-history confirmation,
asset-category filtering, combined/people/ticker results, no-result states and
profile/ticker navigation. User queries and the list position survive child-page
navigation. Me includes all five tabs, compact bookmark cards, followed tickers,
the supplied Playbook/Automation empty states, profile editing and appearance.
Following and bookmarks share local state across their entry points.
The create button opens the existing Alva conversation entry; no publishing backend
or new thesis-authoring workflow is fabricated.

Root tabs retain their directional transitions. Detail/profile pages slide in and
back out, hide the application tab bar, and preserve their parent state.
Reduced motion remains supported. Real mobile browsers omit simulated system bars;
desktop previews retain the selected device's safe areas. Below 360 CSS pixels the
existing logical 360 layout scales uniformly. The Search field displays 14/22 text
while retaining a 16px layout font to prevent Safari focus zoom.
